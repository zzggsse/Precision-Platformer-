# 关卡制作

本文讲怎么画关卡。想让引擎支持新的瓦片类型看 [ARCHITECTURE.md](ARCHITECTURE.md)，
想知道跳跃能跨多远看 [PHYSICS.md](PHYSICS.md)。

---

## 一、工作流

```
assets/levels/level1.ascii  --gen-level.ps1-->  level1.tmx  --Tiled 精修-->  游戏里按 F5
       （种子，手写）                            （编辑器格式）            （改完立刻试玩）
```

```powershell
# 改完 .ascii 后编译成 TMX
scripts\gen-level.ps1

# 或者指定别的文件
scripts\gen-level.ps1 -AsciiFile assets\levels\level2.ascii -TmxFile assets\levels\level2.tmx
```

**为什么要有 ASCII 这一步**：手写 40x22 的 CSV 数组太容易错（一个逗号错位整张图就废了），
而用 Tiled 从零画第一版也慢。ASCII 草图好改、能 diff、能一眼看出关卡形状；
编译出的 TMX 再丢进 Tiled 做像素级精修。

> ⚠️ **约定：ASCII 是种子。**
> 一旦你用 Tiled 精修过 TMX，就**以 TMX 为准**，不要再跑 `gen-level.ps1` 覆盖它
> （或者把精修结果另存成 `level2.tmx`，把 `level1.ascii` 只当历史记录）。

## 二、ASCII 图例

| 字符 | 含义 | 图层 | 说明 |
|---|---|---|---|
| `.` | 空 | — | |
| `#` | 地表 | solid | 顶部带草，用于地面最上面一行 |
| `=` | 泥土 | solid | 地面内部 |
| `B` | 石块平台 | solid | 悬空平台的默认外观 |
| `^` | 朝上尖刺 | hazard | 放在地面上 |
| `v` | 朝下尖刺 | hazard | 挂在天花板下 |
| `<` | 朝左尖刺 | hazard | 挂在右侧墙面 |
| `>` | 朝右尖刺 | hazard | 挂在左侧墙面 |
| `:` | 背景砖 | bg | 纯装饰，不参与碰撞 |
| `P` | 出生点 | — | 该格本身为空，同时生成 `spawn` 对象 |
| `G` | 终点 | — | 该格本身为空，同时生成 `goal` 对象 |

以 `|` 开头的行是注释（写在文件头部说明关卡意图）。

**校验**：`GenLevel` 会检查所有行等宽、字符合法、恰好一个 `P` 和一个 `G`，
出错时打印具体是第几行第几列有问题。

### 一个最小例子

```
|
| 出生点在左边，跳过地面尖刺，跳上平台，碰到旗子。
...P..........^^........G...
######..######..######..####
```

（注意：`G` 那格本身是空的，旗子是渲染层按 goal 矩形画上去的。）

## 三、用 Tiled 精修时的约定

手工在 Tiled 里画也要遵守这些，否则加载会报错或图层被忽略。

### 地图设置

| 项 | 要求 | 不对会怎样 |
|---|---|---|
| orientation | `orthogonal`（正交） | 报错 |
| 无限地图 | **关闭** | 报错 |
| 瓦片尺寸 | **16 x 16** | 报错 |
| 图集 | **内嵌**（不要外部 TSX） | 报错并提示怎么改 |
| 图层格式 | **CSV** | 报错并提示怎么改 |

> 图层格式在 Tiled 的「地图 → 地图属性 → 图层格式」里改。
> 默认新建地图就是 CSV，但如果你改成 base64/zlib 就会加载失败。

### 图层名字必须正好是这三个

| 图层名 | 作用 | 不参与碰撞 |
|---|---|---|
| `bg` | 背景装饰 | ✔ |
| `solid` | 实心碰撞 | ✘（这就是碰撞层） |
| `hazard` | 尖刺 | 判定框自动按方向内缩 |

名字不对的图层会被**忽略**，并在控制台给出 warning（不会崩，方便边改边试）。

### 对象层里两个对象，Name 必须正好是

| Name | 作用 | 说明 |
|---|---|---|
| `spawn` | 出生点 | 玩家碰撞盒左下角会放在这个矩形的左下角。**缺少会报错** |
| `goal` | 终点 | 碰到这个矩形即通关。旗子按这个矩形画出，所以**拖动它画面会自动跟随** |

> Tiled 1.9 之后对象的「类型」字段从 `type` 改名叫 `class`。
> 加载器两个都认，`name` 优先。

### 越界规则

| 位置 | 行为 |
|---|---|
| 左右两侧之外 | **视为实心**（当墙用，玩家跑不出去） |
| 底部之下 | **视为实心**（防止掉出世界） |
| 顶部之上 | 视为空（天空开放，可以跳出去） |

所以关卡不必自己画左右边界墙。但**"掉下去就死"的深坑要自己放尖刺**，
因为底部有隐形的地板接着。

## 四、关卡设计规则（来自实测）

详细推导见 [PHYSICS.md](PHYSICS.md)。画之前先记住这四条：

| 想做的事 | 上限 |
|---|---|
| 台阶高差 | **≤ 3 格**（满跳 3.33 格，4 格上不去） |
| 需要小跳的地方 | **1 格**（轻点 1.04 格） |
| 平地缝隙 | **≤ 5 格**（平跳 5.60 格） |
| 升高 3 格时横移 | **≤ 3 格**（实测 3.50 格） |

**尖刺判定的实际大小比贴图小**：16x16 的尖刺，判定框两侧各内缩 4px（还剩 8px 宽），
根部内缩 2px。玩家判定尖刺时还会再各缩 1px。

意思是：**擦着刺尖过去不会死**。想确认具体位置就按 `F1` 打开调试视图直接看。

## 五、画关卡的实操建议

1. **先开 `F1`。** 调试视图会画出实心格子轮廓（蓝）、尖刺判定框（红）、
   玩家碰撞盒（绿）、脚下 1px 探测线（黄）。做这类关卡时这是最高频的工具 ——
   看不见判定框就永远调不明白"为什么这个缝过不去"。
2. **用 `F5` 建立心理时钟。** 改 TMX → 切回游戏 → 按 `F5` → 立刻重试，
   全程不到 2 秒。别关游戏重开。
3. **`F5` 失败不会崩。** TMX 改到一半语法坏了，游戏会保留上一个可用关卡，
   把错误显示在 HUD 上（黄色文字）。修好再按一次 `F5` 即可。
4. **`R` 重开本关**（清零死亡数和计时），**`ESC` 退出**。
5. 出生点被埋进实心方块时，HUD 会显示 `WARNING: spawn point is inside solid tiles`。

## 六、换掉占位美术

直接覆盖这两个文件即可，**路径和尺寸不变，代码一行都不用改**：

### `assets/tiles/tiles.png`

- 格式：4 列 x 4 行的网格，每格 **16 x 16**，共 16 格（整图 64x64）；
- **顺序必须和 `src/pixelperil/level/Tiles.java` 的常量一一对应**：

| 图集下标 | gid | 常量 | 内容 |
|---|---|---|---|
| 0 | 1 | `GROUND_TOP` | 地表（顶面带亮边） |
| 1 | 2 | `DIRT` | 泥土 |
| 2 | 3 | `BLOCK` | 石块平台 |
| 3 | 4 | `SPIKE_UP` | 朝上尖刺（尖端在**上**） |
| 4 | 5 | `SPIKE_DOWN` | 朝下尖刺 |
| 5 | 6 | `SPIKE_LEFT` | 朝左尖刺 |
| 6 | 7 | `SPIKE_RIGHT` | 朝右尖刺 |
| 7 | 8 | `GOAL` | 终点旗 |
| 8 | 9 | `BG_BRICK` | 背景砖 |
| 9~15 | 10~16 | — | 预留（单向平台、传送门等） |

> `gid = firstGid + 图集下标`，而 `firstGid` 就是 TMX 里的 `firstgid`（默认 1）。

**尖刺画法很重要**：贴图画的是三角形，判定框是按方向内缩的矩形
（见 [PHYSICS.md](PHYSICS.md)）。换新尖刺贴图时，让三角形的"实心部分"
大致落在判定框范围内，否则会出现"看着没碰到却死了"。

### `assets/sprites/kid.png`

- 16 x 16，单帧（目前没有动画）；
- 碰撞盒只有 8x12，精灵比它大是有意的（见 [ARCHITECTURE.md](ARCHITECTURE.md)）；
- 精灵相对碰撞盒的偏移在 `Config.SPRITE_OFFSET_X/Y`。

### 重新生成占位图

想改占位图本身（而不是换成真素材），改 `tools/GenAssets.java` 然后：

```powershell
scripts\gen-assets.ps1
```

**注意**：这个脚本会**覆盖** `tiles.png` 和 `kid.png`。换成美术素材之后就不要再跑了。

### 加新瓦片类型

1. 在 `Tiles.java` 加常量；
2. 在 `GenLevel.java` 加 ASCII 字符映射（可选）；
3. 如果是新尖刺方向，改 `Tiles.spikeHitbox()`；如果是新实心块，碰撞不用改（非 0 即实心）；
4. `TileRenderer` 不用改 —— 它按下标自动切片，图集里画了就能用。
